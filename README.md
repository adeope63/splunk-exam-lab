The application and setup instructions are in [splunk-exam-lab](splunk-exam-lab/README.md).

```sh
cd splunk-exam-lab
./start.sh
```

See the application README for dependency installation, Windows and Docker instructions, question-bank scope, and validation details. Local study data and installed dependencies are excluded from version control.
